Active Directory

How to fill this out

Enter your AD DNS domain. The domain controller is optional and will be discovered automatically when left blank.

Add usernames and groups one per line. Groups may use a group name, sAMAccountName, SID, or distinguished name.

Users authenticate directly against Active Directory. No Entra ID or service account is required.

Microsoft Entra ID

How to fill this out

In the Entra portal, register an application, then copy its Directory (tenant) ID and Application (client) ID here and add a client secret.

Register the redirect URI below as a Web platform redirect on that application. It must be the public address of this site followed by /api/auth/entra/callback.

Authorize administrators by user principal name, by security group object ID, or by app role value. App roles are the most reliable for users who belong to many groups.

Sign-in happens on Microsoft's own page, so multi-factor authentication and Conditional Access policies apply. Changing any setting here signs out current Entra sessions.
